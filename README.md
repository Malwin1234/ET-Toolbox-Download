# ET-Toolbox

Rechner und Nachschlagewerke für Elektrotechnik-Studierende: 61 Werkzeuge in einer App, komplett offline, ohne Tracking.

**➜ [Neueste Version herunterladen](../../releases/latest)**

## Installation

| Gerät | Datei | So geht's |
|---|---|---|
| **Android** | `ET-Toolbox-x.y.z.apk` | Herunterladen und öffnen. Beim ersten Mal „Installation aus unbekannten Quellen“ erlauben. |
| **Mac, Windows, Linux** | `ET-Toolbox-x.y.z.html` | Herunterladen und doppelklicken. Die App öffnet sich im Browser und braucht kein Internet. |
| **iPhone, iPad** | `ET-Toolbox-x.y.z.html` | In der App **Dateien** sichern. Dann die kostenlose App **Microsoft Edge** installieren, die Datei lange antippen und über **Teilen → Edge** öffnen. Einfaches Antippen zeigt nur eine Vorschau, in der die Rechner nicht reagieren. |

Eingaben, Favoriten und das Design (hell/dunkel) bleiben gespeichert.

## Werkzeuge

| Bereich | Inhalt |
|---|---|
| **Werkstatt** | Metrische Gewinde (Kernloch, Flanken-/Kerndurchmesser, Spannungsquerschnitt, Schlüsselweiten), Anziehdrehmomente, Festigkeitsklassen, Drehzahl Bohren / Drehen / Fräsen, Gewindebohren |
| **Bauteile** | Widerstands-Farbcode (4/5/6 Ringe, beide Richtungen), SMD-Code inkl. EIA-96, Kondensator-Code, E-Reihen, IC-Pinouts mit Zeichnung |
| **Gleichstrom** | Ohm/Leistung, Reihe/Parallel, Spannungsteiler, LED-Vorwiderstand, Spannungsfall, R(ϑ), Stern-Dreieck, RC/RL, Akku-Laufzeit |
| **Wechselstrom** | Blindwiderstand, RLC-Impedanz, Schwingkreis, 1~/3~-Leistung, Kompensation, Effektivwerte, dB, Filter, Trafo |
| **Elektronik** | NE555, LM317, OPV-Grundschaltungen, Transistor als Schalter, Z-Diode, Leiterbahnbreite, AWG |
| **Digital & IT** | Zahlensysteme, Bitoperationen, Boolesche Algebra mit KV-Diagramm, Logikgatter, IPv4-Subnetting, IEEE 754, ADC, ASCII, RJ45 |
| **Mathematik** | Wissenschaftlicher Rechner (komplex, ∥-Operator), Polynom-Nullstellen, LGS, komplexe Zahlen, Dreiecke, Einheiten, Formelsammlung |
| **Tabellen** | Konstanten, Präfixe, Leiterwerkstoffe, IP-Schutzarten, Elektroinstallation, griechisches Alphabet, ET-Formeln |

## Hinweis

Die Werte sind gegen Normen und Datenblätter geprüft, die Quelle steht jeweils beim Werkzeug. Schnittdaten und Anziehdrehmomente sind Richtwerte. Pinbelegungen vor dem Einbau mit dem Datenblatt des Herstellers abgleichen.

Fehler gefunden? Gerne als [Issue](../../issues) melden.
